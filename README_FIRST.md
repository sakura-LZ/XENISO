# LIMEN · Codex 精简交接包 V3（2026-10-20）

**先读本文件，按阶段加载，严禁开始就全文扫描项目说明。**

## 产品一句话
LIMEN「临界」面向医学生，以职业兴趣量表与自填医学经历为入口，连接职业实际任务、三类跨学科方向与升学准备路线。目标不是劝学生转行，也不是推算录取率。

## 最短用户主线
1. 访客匿名进入 → 填学籍/可选学业科研资料 → 做 O*NET Mini-IP 30题；
2. 生成**报告一**：兴趣结构、能力证据、最多三个值得探索的方向（允许其他方向和继续医学）；
3. 进入专业知识库（3大/9细分），了解真实职业任务 → 体验一个工作台；
4. 用户选择目标方向、填计划转专业年份和可投入时间 → 生成**报告二**：技能/课程缺口、院校待核验清单、按路径定制行动计划。

## 如何给 Codex 使用，节省 Token
- 把 `LIMEN_Codex_V3` 文件夹完整放入新项目根目录；将此文件夹下的 `AGENTS.md` **复制到项目根目录**（不要存在两份冲突的根规则）。
- **首次指令只要求读取**：`README_FIRST.md`、`AGENTS.md`（如已放根目录则读根目录）、`docs/00_SCOPE_AND_ACCEPTANCE.md`。
- 只执行当前阶段任务；需要哪个文件才加载哪个，详见 `docs/01_BUILD_PLAN.md`。
- `data/*` 是实现契约，Codex 不要每轮重新把整个 JSON 输出到聊天中。
- 阶段末只汇报：改动文件、测试结果、遗留问题、下一阶段。先交付能运行的垂直切片，不做“全站一键生成”。
- 提示词见 `prompts/CODEX_PROMPTS.md`，第一条 P0 即可直接复制。

## 当前必须由开发者执行
1. **撤销屏幕截图中曾泄露的 O*NET Key，重新生成**，仅放入 `.env.local` 的 `ONET_API_KEY`；本压缩包未含任何密钥。
2. O*NET API 账号已生成不等于测评端点已联通，P0 必须真实请求验证。
3. 中文 Mini-IP 题目是对原版的翻译改编；保留原文、题号、维度和版本映射。对外公开发布前按开发者许可落实验证和署名，不能宣称中文译本已完成验证。
4. 全国招生数据库并无已确认的可靠免费官方批量 API；第一版填入少量有官方来源的项目，没核实的内容显示“待核实”。

**禁做**：录取概率、成绩/GPA心理推断、强制专业考试、全国招生爬虫、复杂多Agent、支付、自动搜索导师私人信息、虚构案例数据当真实结果。
