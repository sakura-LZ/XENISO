## 四、几个不好找但必须修的缺陷

**1. 刷新瞬间局部变白（首页）**
逐帧截屏 183 帧定位：不是 canvas，是那张解剖图版在 JPG 解码前露出容器底色 `#f8f4e8`，
包围盒与元素 rect 完全重合，持续 137ms。用户说的"一个瞬间，然后出图"就是它。整块删除后复测，
加载全程无"先亮后暗"的瞬时块。

**2. 色键墨迹"画得再深落纸也淡"**
根因是原来用半透明 alpha 画墨，墨先与绿幕混色、再被抠掉一半。改成不透明实色四档表达浓淡、
密度靠笔数。深色像素 **2.08% → 9.16%**（线上实测），四形态间 17.5–19.5% 像素变化。

**3. 折叠里的内容永久停在透明**
滚动叙事层给将要入场的元素打 `opacity: 0` 起始态。收起的 `<details>` 里元素没有布局盒子，
IntersectionObserver 永远不触发 → 用户展开看到空白。`/explore` 实测 6 个 `<li>` 卡死。
修法：收起的 details 内不武装 + 展开时放行。修复前 6 → 修复后 0。

**4. 折叠展开后高度为 0**
曾用 `::details-content { block-size: 0 }` 做展开动画，实测展开后内容可见但 `<details>` 停在 47px、
内容溢出卡片。改成只动 opacity/translateY。实测 47 → 258 → 47px。

**5. WebGL 上下文丢失**
线上连续截图时上下文丢了 2 次，画布变永久空白。补 `webglcontextlost` 处理：preventDefault +
重建资源。告警消失。

**6. 收进折叠里仍然是堆砌（文库）**
单条来源记录的"展开原文摘录"原本 18148px。改成正文容器限高 + 内部滚动（原文一字未删）→ 495px；
折叠 75（含 65 嵌套）→ 41；每页记录 12 → 5；招生表格从常显改独立折叠（原本 2918px 表格
与下方列表是同一批数据重复渲染）。41 个逐个展开最大 1209px。

## 九、第二轮盲审（6.5/10）与整改

第二轮换了一位独立评审员，按同一份 oil-ui-pro 手册盲审，总分 **6.5/10**（上一轮 6.0）。
它抓到的第一条直接推翻了第一轮的一处整改，这里如实记下。

### 9.1 它推翻了我上一轮的什么

上一轮我把 `.t-section` 和 `data-xn-stagger` 接进了内页，并在交付说明里写成"内页动效已接线"。
**这个说法不成立。** 根因在 `xeniso-motion.tsx`：`setTimeout(release, 2200)` 会把所有仍在
`pending` 的元素一次性放成不透明。真实读者在第一屏停留 2.2 秒是必然的，所以往下滚时区块
早已不透明——错峰对读者根本不存在。评审实测 t=3.2s 时，视口下方 1131px 的错峰宿主已经是
`data-state="in"`，子项 opacity 正在视口外从 0.898 淡到 0.677。

也就是说：接线做了，但被兜底抵消了。**这是"改了但没效果"的典型，比没改更糟——因为它看起来已经完成。**

改法与实测见 9.2。

### 9.2 这一轮的四处修改

| 项 | 改法 | 实测 |
|---|---|---|
| 错峰兜底 | 只放行"顶边已越过视口下沿"的元素；兜底 2200→9000ms 只做卡死救急；滚动时按几何补放行（IO 异步，快速滚动会整段跳过）；打印前全放 | /report/initial：t=3.6s `pending=7` 且折叠下方宿主仍 `pending`；滚到 900 放行到 3；滚完 `pending=0`、`invisible=0` |
| 三套按钮 | `.button` 由 999px 胶囊改 2px 直角 + 同一组弹性缓动；`.atlas-btn` 显式补 `border-radius: 2px`；删 `profile.css` 那处 2px 覆盖 | 20 个路由×视口组合，按钮圆角全部 `r=2px` |
| 赭石文字 | 新增 `--ochre-ink: #6b4a15` 专供文字（`--ochre` 只留线/边框/印章/填充），用负向后行断言只替换独立 `color:` | 8 条路由低于 AA 的文字样式数 = 0 |

### 9.3 两处我自己的测量 bug（记下来避免下次误判）

1. **type-audit 把收起 `details` 里的子元素算成可见。** 收起折叠的子元素仍有内在尺寸，
   `getBoundingClientRect()` 非零，于是被计入"可见文字"，让 `/explore` 详情页字数从
   676 假跳到 6176。加 `closest("details:not([open])")` 排除后与基线完全一致
   （`docH 3565`、`chars 849` 均未变）——**页面根本没变，是尺子错了**。
2. **contrast 脚本把 `color(srgb 0.945 0.917 0.851 / 0.9)` 的 0..1 浮点当成 0..255**，
   算出 1.27:1、1.59:1 这种荒谬值，报出 10 处假违规。修正解析后为 0 处。
   `--ochre-ink` 本身一直是达标的（6.7:1）。
