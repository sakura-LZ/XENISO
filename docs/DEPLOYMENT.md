# 部署准备（尚不可发布）

此文档只提供准备步骤，本轮没有部署、推送或开通付费资源。

## 构建与运行

- Node.js 22+，执行 `npm ci`、`npm test`、`npm run lint`、`npm run build`、`npm run check:client-secrets`。
- 本机完整构建预览：`npm run start -- --port 3001`，监听 127.0.0.1，避免公开端口。
- 未来部署主机应使用受信任的 HTTPS 反向代理；设置服务端环境变量与 `LIMEN_APP_ORIGIN` 为实际 canonical origin。禁止把任何 key 改为 `NEXT_PUBLIC_`。
- 关闭 `LIMEN_ENABLE_P0_CONSOLE`，AI 默认关闭。只有服务及费用获具体授权后才能启用 AI。
- `.env.local` 不进入 Git、容器上下文、网页静态文件、截图、日志或构建报告。当前客户端扫描只报告文件计数，不回显值。

## 发布前仍需完成

1. O*NET 真实题目与计分端点通过，记录数据库/API 版本与返回时间；中文译稿人工复核、署名与发布条件核验。
2. 顺序执行三份数据库 migration，启用匿名登录；`npm run verify:p0` 实测资料/测评/体验/报告四表的两个匿名身份隔离、刷新与本人删除级联路径。脚本只创建合成访客并清理。
3. 真实 R1 与 R2 分别生成、刷新读取、来源对照；AI 结构校验不能证明每句话语义正确，需要报告角色用例与证据审查。没有真实调用记录则不可宣称 AI 验收通过。
4. 1440/820/390px 的主页面布局与合成交互已检查，详见 `testing/LOCAL-acceptance.md`；截图能力恢复后补做视觉验收，并完成真实访客删除和全链路状态检查。
5. 为公开匿名注册配置项目支持的防滥用手段，设置共享限流/预算控制；当前进程内 limiter 只适合封闭开发，不是生产方案。检查依赖版本与供应链告警，不隐藏告警。
6. 隐私告知应说明匿名身份丢失、保留与删除、自述数据和 AI 提供方处理范围；确认没有真实档案存在公开存储。

招生目录当前为空。允许以“待核验清单”形式演示；不得填入未验证学校、考试科目或可报考结论。

## 回退与恢复

- 外部服务故障时：保留明确错误，仍可使用公开手册、文档交互演示、合成工作台和规则草案。禁止把 simulation 切换标签冒充真实结果。
- 重启开发：先读 `docs/PROGRESS.md` 与 Git 状态，只做未完成验收。所有数据库迁移尚未在真实环境执行，不能以文件存在认定部署成功。
- 发布需另行明确授权；完整验收前保持 Goal 未完成。
