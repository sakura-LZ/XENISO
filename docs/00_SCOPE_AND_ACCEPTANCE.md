# LIMEN MVP 范围（冻结）

## 定位与目标用户
中国医学本科生（临床、预防、口腔、医学技术等），既包括不确定是否转专业的探索者，也包括已有方向的转型者。产品帮助**探索与规划**，不进行心理诊断、院校录取预测或承诺报考资格。

## 6个模块（唯一业务范围）
1. **个人画像**：访客会话、学籍、可选 GPA/年级排名/成绩单（浏览器解析）、科研/论文/实验/编程、爱好、工作偏好、可选私密转型动机/自我评价、计划转专业年份/每周时间；Mini-IP 30题。
2. **初步分析 R1**：O*NET 官方六维结果+职业；来自个人资料的技能证据；探索建议和未知项。
3. **知识库**：3一级、9细分；每方向给研究内容、典型工作活动、技能与课程、代表职业、权威来源及对应升学项目（可空）。
4. **职业体验**：围绕一个医疗问题，至少做完 1 个高质量的工作台；另2个如时间不足仅作为说明页且不能假装已实现。
5. **综合报告 R2**：用户选方向后关联体验、兴趣、证据、课程差距和现实约束；允许“不确定/继续医学”。
6. **转型规划**：目标方向课程路径、技能练习、科研入门、统考/推免/申请差异、官方核验条目和每周可执行安排。R2 内呈现，无需额外页面。

## 两条旅程
- **不确定方向**：匿名进入 → 填最低背景 → Mini-IP → R1 → 知识库/体验 → 自选方向或继续探索 → R2（必要信息补齐才生成时间计划）。
- **方向明确**：匿名进入 → 背景+Mini-IP → R1 → 直达目标知识库 → 体验 → R2+学习路径。

## 不做清单
不强制专业知识考试；不做 AI 乱写的导师推荐；不做全国完整招生数据；不做付费功能；不做病人真实医疗结论；不按点击时长/题目正确率判定兴趣；不训练预测人格与录取模型。

## 关键验收（必须有运行证据）
1. 两名匿名访客彼此无法读取报告和资料；同一会话可以继续填写；存在删除功能。
2. 成绩表导入可查看预览、纠错与仅保存必要结构化字段，未上传也可继续。
3. Mini-IP 原题索引与回答码对应准确；以官方端点验证 30题计分，含失败处理；若存在接口格式问题则明确阻塞并展示可信回退状态。
4. R1 和 R2 是不同报告；R1 不需要选择专业，R2 需要目标方向与必要计划参数，来源明确。
5. 9细分方向可浏览且点击职业打开对应来源；资料不足标待补充。
6. 至少1个工作台有操作→数据变化→具体成果导出；合成与真实论文资料有清楚标签。
7. 三类测试角色：高兴趣零基础、成果很多但兴趣一般、尚未决定；不得给出虚构成功概率。
