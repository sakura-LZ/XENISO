## 三种布局选择

这些是依据上述功能组织和用户要求提出的 LIMEN 页面方案，不是声称参考网站现有页面与下述布局完全相同。

### A. 面试双栏（推荐用于面试体验）

- 页顶：返回职业体验、目标方向、已读取的个人画像摘要；摘要可展开，不占一整条常驻侧栏。
- 主体左 42%：数字人半身画面，人物姓名 / 角色，正在聆听 / 回答的状态；仅保留必要音频控制。
- 主体右 58%：当前题目、对话记录、固定底部输入框；“文字 / 语音”切换紧邻输入区。
- 题目分项置于工作区上方横向标签：自我介绍、中译英、英译中、专业问答、生活问答。每项记录完成情况，允许单独练习。
- 结束后同一页切到“回答回顾—具体证据—下次可改什么”，可下载草稿并继续行动规划。

优点：完全符合用户提出的左人物右输入，视线集中。缺点：长材料与长对话会争夺右栏空间；因此材料只做可展开抽屉。手机改为顶部短人物画面 + 下方题目与输入，不机械缩成两栏。

### B. 任务工作台（推荐用于职业体验）

- 顶部横向阶段：了解情境 → 查看资料 → 完成任务 → 复盘。
- 左 30%：数字人导师与当前目标，可切到已读取的画像摘要。
- 右 70%：资料 / 我的作答两张标签页；资料应含来源、可引用片段和必要附件。底部保留向导师提问入口。
- 当前任务始终有可见产物，例如为某个具体案例整理判断依据、比较方案、写出可检验的下一步；任务随职业方向变化。

优点：资料和产物占主导，数字人辅助探索，符合“职业体验”本意。缺点：比双栏对话更复杂，应先只放一个任务；不要同时铺六七张卡片。

### C. 视频主舞台 + 侧边抽屉（备选）

数字人占主要画面，题目、字幕与控制浮在下沿，文字对话 / 材料按需从右侧展开。

优点：人物存在感强，适合短口语和自我介绍练习。缺点：中文长题、中英对照和材料研读不舒服；用户切成文字模式后还要多一步操作。建议只作为以后“专注口语”模式，不作为当前默认。

## 推荐取舍与实现边界

推荐职业体验用 B、面试体验用 A，进入页只给两个清楚的入口；两者使用同一配色、输入控件、结果页结构，但不共用整套左侧主流程菜单。全流程仍是 **个人画像 → 初步评价 → 职业体验 → 行动规划**，职业问卷属于个人画像内部。

预览阶段若尚未接入实时数字人，人物区域应能显示等待 / 讲话的视觉状态，但不能把循环人物视频或浏览器朗读描述为真实数字人理解与口型同步；没有语音识别支持时应保留文字输入。这里涉及真实能力的状态提示是必要反馈，不应扩写成整屏免责声明。

用户已有明确的结构建议可先实施。尚待用户挑选的是 A/B 的画面比例和人物风格；不用为选择参考而阻塞已明确的首页、个人画像分块、基本情况表单和问卷设计。
