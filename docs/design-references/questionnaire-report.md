# 问卷与报告生成：参考核实及落地建议

调研日期：2026-10-21。仅调研公开参考，未提交人格答案、登录或修改产品代码。

## 16Personalities 中文问卷

来源：[中文人格测试](https://www.16personalities.com/ch/%E4%BA%BA%E6%A0%BC%E6%B5%8B%E8%AF%95)。公开页面 HTTP 200，并通过浏览器检查桌面与 390 × 844 手机视口。完成后恢复视口、关闭临时调研页。

已核实的设计：

- 首屏居中大标题，下方三个并列步骤卡：完成测试、查看详细结果、释放你的潜力。每块有插画、步骤编号、短标题、一句话说明。LIMEN可保留这个层级，但替换内容，不沿用高级付费资料文案。
- 当前页面为每组 6 题、全卷 60 题。题目与选项共享宽松的横向内容区，题间用细分隔线，不套多层圆角卡。桌面题目实测 22px / 30px 行高、字重 660；手机为 19px / 24px。
- 原站为 7 档同意程度：两端圆大、中央圆小；桌面端点文字在圆圈两侧，手机挪到下一行两端。手机圆直径为 46 / 38 / 32 / 26 / 32 / 38 / 46px，7 圆保持单行。
- 原生 `input[type=radio]`，每题用同名组、`fieldset`、含题号与题干的 `legend`；每档有明确 `aria-label`。装饰圈和勾选图案对辅助技术隐藏。不能只用无名称圆形 div 实现。
- 可访问文本包含“第 n 题，共 60 题”，底部有“转到下一组问题”。本轮未作答，没有验证作答后的进度动画或自动滚动；初始 DOM 未发现 `progress` 或 `role=progressbar`，不能声称原站有某种百分比进度行为。

### LIMEN 采用方案

1. 问卷页保留三块简短介绍，建议“探索工作兴趣 / 按真实感受选择 / 汇入个人画像”，每块一句说明，不放多余防御性小字。
2. 必须保留 **O*NET Mini-IP 30题、原始题号、RIASEC、版本和5档 answer code**。借鉴的是圆形选项和排版，不能变成60题、7档，也不能改成MBTI维度；答案语义仍是原有兴趣程度，不换成“同意/不同意”。中文翻译来源继续独立标注。
3. 桌面题干建议 24px / 1.5，手机 20px / 1.5；五档单行，整组不横向滚动。实际点击热区至少 44 × 44px，视觉圆可以小于热区。绿色填充加勾选反馈，键盘焦点圈明显，避免仅靠颜色区分。
4. 五档宜都显示短标签；手机可换行标签而不打乱档位。等大圆也可，避免视觉大小把回答暗示成好坏。若采用两端较大，务必保持命中区域一致。
5. 真实进度显示“已完成 12 / 30”，由实际已答题数计算；下一组校验未答项并定位。返回画像模块后保留填写状态，可修改。兴趣题是画像模块内部第二部分，不单独增加一套全站主流程侧栏。

## LaunchEx Submissions 报告生成参考

用户文件：[报告生成.md](../../../报告生成.md)。公开预览：[Mux 视频](https://stream.mux.com/m8zP8lIqA4cCWuecz800MQGSoJZhAIw7Zk9Yt2s6d00Ic.m3u8)。

文件明确标记 `paid_only`，全文只有重构提示词，并非原始付费提示词。公开预览通过 ffmpeg 获得三个可用早期采样帧：浅底、中央金属流体物件，两侧各三条短信息，顶部大标题；中心物件形状在帧间变化。HLS 后续出现 NAL / I/O 解码错误，因此只核实了这些画面，未确认完整时长或全程交互。采样图保存在 `work/pathways-redesign/launchex-reference.jpg`，仅供内部参考，不作网站背景资产。

### LIMEN 采用方案

- 借中央动效与两侧信息的构图，生成时居中使用 **LIMEN** 字标，做缓慢的遮罩流动、淡入淡出；背景是浅绿白，字标深绿。无需复制金属球或网页录屏。
- 两侧只放真实待合并内容，例如左“基本情况 / 医学经历”，右“兴趣回答 / 探索方向”。手机上下排列，字标居中。
- 仅在真实报告计算/请求未完成期间播放。没有服务器进度时只写“正在整理个人画像”，不用假百分比、假的分析步骤，也不要为了展示动画故意延迟结果。
- 完成后在画像模块下方出现报告摘要、展开、下载；失败则保留输入并给重试。`aria-live` 只宣告状态变化，减少动态偏好下显示静态字标。

可选视频生成提示词（当前 CSS 字标即可，不阻塞实现）：

> 生成 6 秒循环背景，16:9，固定镜头，柔和灰白偏鼠尾草绿背景，中央留出宽敞空白供网页叠加 LIMEN 字标。细腻半透明绿色流体从中央两侧缓慢汇聚又散开，运动克制，干净高级，无粒子飞散，无闪烁，无蓝紫霓虹，无文字、字母、Logo、界面、人物或音频。首尾自然衔接，边缘保持安静，适合报告生成等待状态。

字标由 HTML 叠加以保持清晰和可访问性，避免视频模型拼写错误；不把视频当作报告进度证据。
