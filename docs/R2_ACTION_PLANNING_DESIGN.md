## 1. 旧版的问题

旧版阶段是四个通用名：**现在开始 / 基础准备 / 实践与复盘 / 申报准备**；任务由方向手册的课程列表直接生成「了解与练习：XX」，再加三条路径核验任务。

1. **不像一份备考计划。** 阶段名与考研实际节奏没有对应关系。真实备考是择校核验、补先修、基础、强化、真题、冲刺、初试之后，有先后也有卡点。
2. **没有「什么时候该做什么」。** 只有依赖顺序，没有时间窗口，读者看不出自己现在落在哪一段。
3. **验收判据含糊。** 「按依赖完成概念笔记」这类说法无法判断做到没做到。
4. **文案像免责声明。** 大量篇幅重复「不承诺进度」「未知就是未知」，说清了不能做什么，没给可以做什么。

## 2. 调研依据

**官方口径**来自 `docs/R2_PLANNING_RESEARCH_NOTES.md` 这一份笔记，内容涵盖研招网管理规定、教育部公告、院校招生简章、推免系统节点、港澳申请制惯例，每条都标了「规定 / 惯例 / 经验」和来源链接。

**方法论部分**（检索式练习、间隔重复、结构化复盘、逆向设计等）是写作时查的通用文献结论，**没有单独落盘成第二份笔记**，因此这里只保留对页面有直接影响的几条，不当作已归档资料引用。

### 决定了产品写法的六条

| 结论 | 对页面的影响 |
|---|---|
| 网上确认**全国无统一日期**，各省级考试院自定 | 只写「查本省公告」，不写日期 |
| 国家线公布与调剂系统开放近年明显提前（2026 年为 2/28、3/27、4/8） | 不写月份，只写「以教育部当年公告为准」 |
| 跨专业是否加试**由招生单位自主确定**（管理规定第五十三条），且章程必须公布加试办法 | 只写「查招生章程」，不下结论 |
| 初试稳定在 12 月倒数第二个完整周末，但这是观察不是规定 | 阶段窗口按月份给，标「以公告为准」 |
| 判据要含**条件 + 可观察行为 + 阈值 + 稳定性**，不能用「看完」「掌握了」 | 判据改成可复现动作，如「连续做对两道」「隔一天仍能复述」 |
| 结构化复盘对绩效有实质提升（d ≈ .67），且必须**强制做减法** | 单独一节复盘，周复盘最后一个问题固定是「下周停掉哪一件」 |

反向的坑，明确不踩：

- **「三轮复习法」的月份划分没有官方定义**，是机构惯例，页面必须标「通行惯例」而不是「规定」。
- **用「刷满多少小时」「看完多少讲」当验收是反模式**：那是进度指标，不是能力指标。
- 「一万小时定律」效应量有实质争议，不引用；「自设中间截止更有效」所依赖的 2002 年论文已于 2026 年撤稿，不引用。

## 3. 新骨架

阶段按升学路径分三套，不再共用四个通用名。目标年份记为 Y。

### 统考（含跨考）

| 阶段 | 窗口 | 依据 |
|---|---|---|
| 定位与资格核验 | Y-1 年 1–3 月 | 官方 |
| 补先修（**仅跨考**） | Y-1 年 1–6 月 | 惯例 |
| 基础轮 | Y-1 年 3–6 月 | 惯例 |
| 强化轮 | Y-1 年 7–9 月 | 惯例 |
| 真题与报名 | Y-1 年 9–11 月 | 官方 |
| 冲刺轮 | Y-1 年 11–12 月 | 惯例 |
| 初试之后 | Y 年 1–4 月 | 官方 |

- 「补先修」只在目标方向不是「继续医学」时出现。留在临床不算跨考，不需要这一段。
- 每段四个内容字段：`window`（时间窗口）、`goal`（这一段干什么）、`exit`（判据）、`verify`（每年要重新核对什么）。
- 每段带 `basis` 标记，页面分成「官方节点」和「通行惯例」两种 chip。这是整套设计里最重要的一条：读者要能一眼看出哪句是规定、哪句是经验。

### 推免

资格与成果盘点 → 材料与推荐 → 夏令营 → 预推免 → 九推填报 → 结果与后续。

### 申请制

条件核验 → 语言考试 → 材料准备 → 网申提交 → 面试与结果。

> 港澳硕士无全国平台、无统一截止日，**不存在官方时间轴**，这一段整体只能用惯例口径，页面已注明。

## 4. 新增的三块

### 4.1 当前位置

用目标年份反算距关键节点的月数，判断现在落在哪一段，页面顶部给一条提示：

> 按通行节奏，你现在应该在「强化轮」这一段。
> 距初试（2027 年 12 月）：还有 4 个月 · 当前阶段：强化轮

三种状态分别处理：还没到起点、正在某一段、窗口已经过去。**不给完成百分比**——进度算不出来，硬算就是编。

实现在 `buildPathwayPlan()` 里，每段附带 `state: "past" | "current" | "future"`，页面据此给时间轴节点分三态：已过收暗并标「已过」，当前段节点做实并标「你现在在这里」。

### 4.2 判据规则

页面上直接说明判据怎么算过：

> 判据只看你能不能做出来，不看投入了多少时间。合上书做题、口述或默写都算，重读一遍不算。同一个知识点隔两三天再自测一次，比当天连看三遍有用。

后两句分别对应检索式练习与间隔重复。

### 4.3 复盘与年度核对

- 三个频率：每周 15 分钟、每月 45 分钟、阶段末 90 分钟，动作各不相同。
- 周复盘六个问题，最后一个固定是「下周要停掉或降级哪一件？只能选一件，选最没用的」——复盘必须能产出减法，否则每复盘一次任务就膨胀一次。
- 单独列出「每年必须重新核对的东西」，把会过时的四类集中放，不散在正文里。

## 5. 文案怎么来的

页面导语由 `gemini-3.8-flash-max` 起草（接口 `https://la-api.vxvxvx.top/v1`），再按 oil-tone 规范逐句改。

**采纳**：封面导语、条件登记导语、阶段计划导语、判据说明、复盘导语、年度核对导语、页脚收尾句。

**改掉的模型毛病**：

| 模型原稿 | 问题 | 改后 |
|---|---|---|
| 系统才会排出对应的阶段节奏和核对清单 | 「系统」「核对清单」是内部词 | 下面才会按它们排出阶段计划 |
| 属于备考经验参考，并不是官方统一标准 | 两个词说同一件事 | 是培训机构和考生群体长期形成的节奏，不是官方规定 |
| 各自需要对齐的项目 | 空泛，说不出是什么 | 各给一组要回答的问题 |
| 招生名额、自命题大纲与初试日期的变动每年都会发生 | 绕 | 这些内容每年都会变，写进计划就会过时 |

阶段内部的 goal / exit 也让模型重写过一版，**没有采用**：它写成「你需要先去研招网……」「整齐存放在了你的本地文件夹里」，命令句过多且编造细节，与这一页「档案」的陈述语气冲突。最终保留自写版本，只从模型稿里取了「招生章程和专业目录」这个具体查证位置。

按 oil-tone 完稿检查过三遍（只读标题和首句能否串起全文、连读是否跳跃、朗读是否拗口），`tone_lint.py` 无告警。

## 6. 边界：这一版仍然不做什么

- 不给录取概率、不给方向排名、不给适合度分数。
- 不写学习时长，任务工作量一律显示「未知」并注明来源。
- 不写死任何每年会变的日期。
- 不编造院校、专业、考试科目、招生条件。
- 招生条目仍为空，页面继续只给核验清单，不给结论。

## 7. 页面结构变化

`#plan-stages` 由四段通用阶段换成按路径生成的真实阶段，并新增一个区块：

| 区块 | 变化 |
|---|---|
| 阶段计划 | 阶段名、时间窗口、「官方节点 / 通行惯例」标记、判据、每年要重新核对什么、任务卡 |
| 阶段计划 · 顶部 | 新增「现在在哪」提示条：一句话结论 + 距关键节点月数 + 当前阶段名 |
| 阶段计划 · 时间轴 | 每段带 `data-state`，已过收暗标「已过」，当前段做实标「你现在在这里」 |
| 复盘与年度核对 | 新增。三个频率 + 周复盘六问 + 每年必须核对的东西 |
| 目录（`xr-toc`） | 从 6 项变 7 项，加入「复盘与年度核对」 |

顺带修掉一个旧问题：封面右上那组印章和 chip 在 390px 下把页面撑出 91px 横向滚动（`flex: none` 的容器窄屏不收缩）。改成 `max-width: 100%; min-width: 0;` 后，360 / 390 / 768 / 1440 四个视口横向溢出都是 0。
