# 本地可操作演示与真实验收边界

启动 `npm run dev`，打开 http://127.0.0.1:3000 。全程只输入合成数据。

1. `/profile` → 使用合成示例 → 可跳过选填记录。学业记录可用 `tests/fixtures/transcript.simulation.csv` 或 `.xlsx`，查看两行预览、修改成绩、确认加入，再保存草稿。刷新后点恢复合成草稿。
2. `/assessment` → 加载官方问卷：当前真实环境曾返回 HTTP 403，应保留失败提示。文档快照交互演示可回答全部 30 题并保存恢复草稿；不会生成 RIASEC，不是测评通过。
3. `/report/initial` → 查看 simulation 证据草案 → 展开课程/技能/项目原始依据；没有官方兴趣就没有兴趣方向推荐。AI 区独立显示实际状态。
4. `/explore` → 浏览九个方向 → 加入两个方向对比 → 打开代表职业的 O*NET 来源。不要把编辑映射当中国报考资格。
5. `/studio/ecg` → 调整阈值 → 设备 A/B 切换 → 选择工程取舍 → 填反思 → 保存并导出成果卡。刷新后点恢复已保存成果。所有数据为 simulation，指标随参数重新计算。
6. `/report/plan?direction=ml_cv` → 读取 simulation 画像与体验 → 自选主目标/两个备选 → 填年份、时间、路径 → 自行分配每周预算，总和不可超可用时间 → 导出规则行动草案。

P4 v2：切换统考、推免、申请制，核对资格/材料/时间窗口三项任务随路径变化；有效条件下显示四个交付阶段。路径未决定或预算超出时禁止导出。个人模式会读取本人已保存的官方兴趣及其版本/返回时间；没有记录时保持未知，合成模式不生成兴趣分数。

P5：桌面为224px侧栏、平板/手机为顶部导航，当前页面有状态标记。全站页脚可进入访客隐私/删除页。三尺寸实际截图及24项CSS测量记录在 `docs/testing/`，不是设计稿。

继续医学或未决定均不强行生成专业路线。课程工作量未知，不杜撰完成日期；招生项目为 0，展示核验任务。

上述演示能验证交互和规则草案，**不能代替官方兴趣→私有 R1→体验→AI R2 的完整验收**。该链路仍需 O*NET 连通、Supabase 迁移与两个身份实测、明确授权且可用的 AI 服务。

真实访客路径：画像页连接匿名访客并保存 → 官方问卷提交保存 → R1 区生成/读取 AI 解释 → 完成工作台并点“保存到当前访客私有记录” → 保存画像中的计划条件 → R2 选择方向并生成 AI 解释。当前缺配置会如实失败，禁止录制为已通过。
