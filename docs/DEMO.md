# V4 本地演示与验收

当前状态以 [CURRENT_STATUS.md](CURRENT_STATUS.md) 为准。合成访客主线证据见 [V4-flow.latest.md](testing/V4-flow.latest.md)。本地正式预览使用 `http://127.0.0.1:3001`；开发服务可用 `npm run dev -- --port 3001` 启动。全部演示使用合成资料和隔离访客。

## 演示步骤

1. `/profile`：按四步填写培养阶段、年级、GPA（例如 3.4/4.0）、英语和一项研究经历，保存个人画像。刷新后读取私有资料，核对字段保留。成绩表可选，可使用 `tests/fixtures/transcript.simulation.csv` 或 `.xlsx` 检查本机解析、预览纠错与确认加入。
2. `/assessment`：加载 O*NET Mini-IP 官方 30 题，完成各组后提交。核对六维结果与官方版本；外部接口失败时显示实际失败信息。当前已有真实官方计分通过记录，不再使用旧快照演示代替计分。
3. `/report/initial`：读取个人画像与官方兴趣结果，查看初步画像、证据和方向建议，点击“生成个人解读”。刷新后可“查看已保存报告”；没有相关证据时保留未知。
4. `/experience`：选择模拟项目或模拟面试。完成三个阶段和复盘，保存私有成果并导出。中途可暂停、刷新、恢复；完成后可读取已保存成果。场景数据标记为 simulation。数字人导师由用户主动连接，文字会话另有独立验收记录。
5. `/report/plan`：选择主目标、备选方向、年份、升学路径和每周时间，分配基础/练习/复盘预算。预算总和不可超过每周可用时间。检查体验成果和准备任务，生成并导出个人行动解读。
6. 刷新 R2，点击“恢复已保存计划条件”，再“查看已保存报告”。修改年份或预算后，旧解读应清空；条件不一致时拒绝套用旧报告。

方向手册 `/explore` 可独立浏览九个方向、任务、入门项目和官方资料，并比较方向。其职业与方向关联属于 LIMEN 编辑映射，招生项目保持待核验。社区 `/community` 提供求助/经验两类，需登录后匿名发布；迁移及合成权限已验收，OTP 邮件与真实注册仍待验收。

旧 `/studio/ecg` 仅重定向 `/experience`，不再演示旧工作台。

## 回归检查

- 修改并保存画像后，旧 R1/R2 应提示更新；仅修改体验后，R1 仍可读，旧 R2 应提示更新。
- 编辑已保存体验的复盘后，旧“已保存”成功提示应消失，重新保存后才显示下一步入口。
- 报告展示可读的来源与任务标题；原始引用和 evidence 结构保留在导出中，便于追溯。
- 用 1440×1000、820×1100、390×844 检查画像、测评、R1、体验、R2、手册与社区；页面不应横向溢出，手机流程导航允许内部滚动。
- 执行 `npm run lint`、`npm test`、`npx tsc --noEmit`、`npm run build`、`npm run check:client-secrets`，在已启动的 3001 服务执行 `npm run test:smoke`。HTTP smoke 不创建账户、不调用外部 AI/O*NET，不替代真实主线验收。

当前合成主线、数字人文字链路和社区权限是不同的验收证据。数字人麦克风/ASR、实际音频与口型、社区 OTP、中文译稿独立人工校对、招生官方信息及 AI 长期稳定性仍待验证。尚未公开部署。
