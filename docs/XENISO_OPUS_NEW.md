# XENISO 异域同构 · Opus 新设计

入口：[新版 HTML](../public/previews/xeniso-opus-new.html)，本机预览 http://127.0.0.1:4186/xeniso-opus-new.html 。从原始 LIMEN 预览分出，未覆盖原文件或之前的 XENISO 稿。

品牌为 XENISO 异域同构，标语 Different Fields. Shared Potential.。保留岩桥场景，标题和输入框居中，桥景稍上移。四入口使用新生成的具体校园与工作场景图片，以宽幅图片、分隔线和一行说明组成横滑画廊。支持触屏滚动、鼠标拖动、按钮和键盘；社区改为细粒子，并尊重减少动态设置。

画像、初评、体验、规划和文库清理低价值旁白；场景显示名称改为具体任务。O*NET 原始数据、译稿版本、答案码与体验计算逻辑保留，simulation 和来源仍可查阅。资料数量和日期收进“资料说明”。本稿报告仍为本地记录，未接入真实官方计分或报告 AI。

## Opus 指导意见与取舍

通过用户提供接口调用 `claude-opus-5-5`，分别以视觉、布局、报告文库三个独立角色评审。原生子智能体通道连续断开，未返回产出；最终采用同一 API 三个并行评审请求，不能把它称作已成功完成的原生子智能体执行。

- 视觉：统一配图叙事、用宽幅横滑展示、降低重复旁白。已采纳。模型建议把标语放到输入框下面，与用户明确要求冲突，未采纳。
- 布局：减少画像序号和英文重复、保留两个独立入口、精简说明。已采纳。隐藏所有 simulation 的建议未采纳，合成数据继续明确标注。
- 文库：分层筛选、正文阅读宽度、元数据折叠。已采纳部分。模型认为 `pageHeader` 会重复眉标，实际函数不展示该参数，不据此修改功能。
- 参考附件多数标明为公开元数据重构稿，不是付费模板原文。仅借鉴留白、并列、左右分区与输入层次；未导入黑紫霓虹、营销文案和指定框架。科学家日宣传稿未加入本站。

图片使用用户授权的 `gpt-image-2` API。bundled CLI 因返回 URL 而缺少 base64 失败，另有供应商 451。用户明确允许适配后，使用本机 URL 适配脚本完成 4 张图片；未修改 skill CLI。生成提示词、调用证据、评审原文和编辑源在被忽略的 `work/xeniso-opus-new/`，可重复构建 `node work/xeniso-opus-new/build.cjs`。图片位于 `public/previews/assets/xeniso-opus-*.webp`。

实际验收见 [测试记录](testing/xeniso-opus-new.latest.md)。未部署，未改数据库，本任务未改正式 TSX 页面。
