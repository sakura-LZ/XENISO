## 修复与限制

- 首次图片请求使用既有 LLM 配置，5 次均返回 403“该分组未启用图片生成”，未生成素材；用户提供图片专用配置后 5 次成功。凭据仅在生成进程环境使用，未写入项目文件。
- 旧版回归有一处期待已被用户要求删除的“先把你的画像准备好”，已改为验证新的缺少画像状态。新增粒子测试发现模拟 DOM 的 `document.hidden` 可为 undefined，已显式归一为 Boolean，最终检查通过。没有删除或跳过原有功能检查。
- **浏览器安全策略拒绝 `file://` 自动打开。未通过更换协议、代理或浏览器绕过；未完成实际网页渲染、1440/820/390 三尺寸截图、触屏手势和原生文件下载验收。**DOM / 模拟几何检查不等于浏览器视觉验收。
- 本轮未运行全项目 `npm test`；未将历史单测、真实数字人或社区记录作为本轮证据。报告仍为本地结构化记录，官方计分与 AI 生成未接入此 HTML。
- 社区已使用网页粒子，外部视频仅提供参考图与提示词，本轮未生成视频。图片是生成的视觉素材，不是职业或科研结果证据。
- 未部署、未改正式 TSX 主题、数据库或已有服务。
