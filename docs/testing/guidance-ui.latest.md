# 使用指南与说明收纳 · 2026-10-24

本轮范围：在当前 Next.js 应用实现可查看的第一版信息收纳。仅前端展示与导航调整，未部署。

## 已交付

- `/guide`：独立使用指南，含画像、初评、体验、规划、文库及常见问题。桌面顶部、手机导航菜单及页脚都有入口。
- `PageHelp`：统一“本页怎么用”，默认收起，提供对应完整指南链接。接入画像、初评、规划、文库。
- 画像：缩短导语；样题、完整选项与官方来源移至可展开区域。
- 文库：原常驻使用说明收进帮助区，保留目录、检索、分类、比较操作。
- 规划：七个结果栏目改为一次展示一个，默认阶段计划；保留深链接和跨栏目锚点，切换时保持组件挂载，避免丢失正在生成的解释状态。打印时展示全部结果栏目。
- 缩短初评与规划导语、规划未完成状态；长方法说明和规划依据按需展开。未知、未核验、合成标记及导出条件继续保留。
- 修复规划长标题窄屏溢出；手机切换栏目时保留目录位置，桌面将所选结果定位到可读位置。
