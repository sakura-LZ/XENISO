# XENISO 字号、规划、动效与用户视频验收

2026-10-22。入口 `public/previews/xeniso-opus-new.html`，本机端口 4186。设计与实现均由用户指定接口的 `claude-opus-5-5` 输出，执行者精确应用返回替换。原始响应、替换和调用证据在 `work/xeniso-opus-motion/`。

- 正文实际计算字号：桌面 18px、手机 17px；表单 16px，探索导航 16px。
- 行动规划由本站规则根据方向、路径、预算、画像与体验生成；展示依据、缺口、行动和成果。生成与导出分开，条件更新使结果失效，允许重新生成。标明 simulation，不冒充线上 AI 报告。

- 页面切换、首页滚动入场、展开和选择反馈有动态；浏览器记录实际运行的 om-rise 动画。
- 社区改为用户提供的 8 秒 1280×720 视频，静音循环、图标暂停、静态封面。桌面和手机实测 readyState=4、currentTime 持续增加、暂停有效。减少动态时视频暂停，运行中的动画为 0。
- 社区空 404 和无效 JSON 显示中文错误，不伪造帖子。
