# 院校调研统一清单与统一模板（所有调研线必须遵守）

> 目的：解决「各院校挖掘水平不一致」的问题。之前上海交大 22 条、哈工大 1 条，无法比较。
> **每所学校必须按同一模板产出同一组字段**，拿不到就明确记录「未发布/未取得」，不许跳过、不许用别的学校内容顶替。

## 二、每校必须产出的 4 类数据（统一模板）

| # | 数据类 | 抓哪里 | 必须拿到的字段 | category |
|---|---|---|---|---|
| 1 | **研究生招生要求** | 研究生招生网「招生简章」「专业目录」 | `admission_requirements`（报考条件）、`cross_major_restrictions`（本科专业限制）、`exam_subjects`（初试科目含代码）、`admission_year` | admissions |
| 2 | **专业要求** | 简章报考条件 / 学院「报考说明」 | `cross_major_restrictions`（**relation 必须是 direct**）、`admission_requirements` | admissions |
| 3 | **课程要求** | 学院「专业介绍」「培养方案」 | `topics`（核心/主干课程）、`training`（培养目标/毕业要求）、`learning_hours`（学分/学时） | learning |
| 4 | **职业出口** | 学院「就业去向」「毕业生去向」 | `career_path`、`employer` | recruitment 或 occupation |

**每校最低要求：≥3 条 fact，且覆盖 ≥2 个类别。** 达不到就在 REPORT 里写「该校仅取得 N 条，缺 X」，不许凑数。

## 三、跨考视角（必须遵守）

分析基点固定为「**本科是医学相关专业**」的考生：
- 临床医学 / 口腔 / 护理 / 药学 / 医学技术类 / 预防医学 本科
- 关注：能不能报、要不要加试、要不要补修课程、有没有白名单
- **不是**「工科跨医学」的视角

目标专业优先顺序：
1. `1051` 临床医学专硕、`1052` 口腔、`1057` 中医
2. `1010` 医学技术、`1058` 医学技术专硕（**医学本科 → 医工交叉最现实通道**）
3. `0831` 生物医学工程、`085409` 生物医学工程专硕、`0777` 生物医学工程
4. `0854` 电子信息（生物医学工程方向）、`0812` 计算机、`1405` 智能科学与技术

## 四、强制规则

1. **每条数据必须附原网站链接**：`source.url` = 实际抓取那一页（不是首页/列表页）。数据在附件 PDF 就用附件直链，并在 `context.evidence_locator` 标明位置。
2. **材料用最新版本**：2027 招生年度 > 2026 > 2025。拿不到最新必须在该记录 `publication_date_note` 写明「XX 年版，非最新」。
3. **literal 必须空白折叠成单行**（10–1600 字符），且与它自己那个 `.txt`/`.raw` **逐字对得上**——采集器会校验，张冠李戴会被判 `no_evidence_matched` 拒收。
4. **`published_at` 只在 artifact 正文逐字可见时填**，否则 `null` + `publication_date_note`。
5. **不许编造**：分数、学制、录取率、报录比、薪资，官网没写就进 `missing_fields`。
6. **ego 浏览器用完必须 `page.close()`**（见 `docs/testing/ego-browser-howto.md`），否则 Chromium 累积吃光内存。
7. 禁止来源：xxxedu / kaoyan / offcn / iqihang / vipkaoyan / BOSS / 猎聘 / 智联 / 研招网转载（chsi.com.cn）等聚合站。
