# LIMEN UI 规范 V3（优先保证产品感而非PPT感）

## 视觉方向
**Editorial academic × professional SaaS**：清晰、简洁、谨慎。关键词：可信、理性、有一点探索感。禁止发光球、满屏毛玻璃、夸张霓虹、没有功能意义的装饰性图标、每页三卡片模板。

- 配色：背景 `#F8FAFC`，画布 `#FFFFFF`，主文字 `#152033`，辅助 `#64748B`，强调 `#315CF5`，边框 `#E2E8F0`。状态色仅用于正确/错误/风险。
- 字体：优先本机可用中文无衬线，英文 `Inter` 或 `Geist`；产品标题32–48px，页标题24–30px，正文14–16px，表格13–14px。不要用极大口号或超小角标。
- 栅格：桌面导航侧栏224px，主要内容最大宽1100px；画像多步表单采用640–760px阅读列；报告双栏（左结论/右依据来源）；手机单列。
- 动效：150–260ms的轻微状态转换；仅用于问卷进度、工作台图表数据变化、抽屉切换。用户可开启减少动态效果。

## 页面组合
1. `/`：品牌+明确“探索方向/已有方向”两个入口，下方可直接浏览公开专业知识库。不用整屏炫技。
2. `/profile`：步骤条固定；基本学籍→学业/科研/技能（可跳过）→工作偏好、自我评价→Mini-IP。保存状态明确，上传成绩表先预览再确认，保护隐私文字可见但克制。
3. `/report/initial`：上方 RIASEC 维度结果（使用官方数据，不伪造百分位）；下面技能证据（可展开原始输入）；右侧候选方向与“为什么”；未评估清楚标注。
4. `/explore`：用研究手册式目录导航 3/9 细分方向，左筛选/目录，右专业叙述、职业任务、技能、课程及原始 O*NET 来源；可比较2方向。
5. `/studio/[id]`：类科研工具台：左项目说明和待办，中间真实交互（信号或图表/规则），右即时结果与概念解释；底部可生成成果卡。
6. `/report/plan`：独立区块呈现方向理由/准备差距/课程依赖/时间安排/招生核验；每个重要事实可追溯数据源。

## 组件
NavShell, SectionHeading, ProfileStepper, TranscriptPreview, ScaleQuestion, InterestBars, EvidenceChip, ProfessionLink, DirectionComparison, WorkbenchPanel, SimulationNotice, ReportSection, ActionTimeline, SourcePopover。

## 反AI味规则
- 禁词：“解锁无限潜能”“AI赋能你的未来”“100%适配”“你是天选之子”。
- 不要一屏出现大量 AI 生成解释，优先展示表格/证据/交互，文本为辅助。
- 表达未知：“尚未测量编程能力”而不是“编程能力不足”。
- 把职业数据来源写清楚；所有自动生成报告要有“本报告是探索辅助，不代表报考资格”的简短页脚，无需每段防御性声明。

## 验收截图与测试
在 desktop 1440px、tablet 820px、mobile 390px 测试溢出、对齐、表单可达、长中文与英文职业名换行、加载/失败/空数据/未填写状态；关注表格、图表、操作工作台而非漂亮静态封面。
