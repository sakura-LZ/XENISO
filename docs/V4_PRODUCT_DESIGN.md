# LIMEN V4 产品改造（2026-10-21）

## 定位与体验
面向医学生的跨学科探索工具。主线：个人画像 → O*NET Mini-IP → 初步画像与方向建议 → 职业体验（模拟面试 / 模拟工作）→ 行动规划。方向手册作为独立公开资源。以本轮用户口述优先于附件中的顺序。

## 当前交付顺序
1. 产品界面与画像：移出开发验收文案；统一页面标题、主操作、导航和留白。基本学籍分培养阶段/年级，其他可补充；GPA与排名成组；科研方向、项目和成果相邻；英语等级、实验技能和经历有示例；偏好加入所需帮助。已有私有保存、文件解析和删除路径保留。
2. SDK A：核查官方端到端SDK的真实接口、鉴权、角色/上下文与会话生命周期；没有凭据不标为已连接，不向浏览器输出Secret。
3. 体验 B–E：双模式入口，首个医学AI产品经理三步任务，结构化产出、明确反馈和暂停恢复；面试阶段有限，不伪装成数字人已运行。完成状态与R2的证据联动需单独测试。
4. 手册：逐方向补充任务、实践、先修和官方资料，而非只列词条。招生只采用已核验来源。
5. 论坛：求助/经验两类，用户已确认登录后匿名发布，其他用户可见；公开帖子与私有画像分离，提供删除、举报和内容边界。

## 数据与范围
复用Next.js/React、现有API、Supabase私有payload与RLS，不更换框架。画像新增字段有默认值，使旧资料可继续读取。英语收集显式状态（含未参加/不确定），不虚构成绩。模拟材料标记simulation；体验表现不等于岗位能力或录取判断。原始成绩单继续仅本机解析，不新增外发。

## 验收
定向数据兼容/验证测试、lint、build、客户端密钥扫描；浏览器检查画像四步、选择和示例、测评加载与错误、体验状态和导出，桌面/手机布局。SDK源码验证与真实会话验收分开。保留原有主线回归，不将旧版本验收记录当作新版本已通过。

## 当前边界
星云真实文字会话、社区迁移及合成权限已通过独立验收；语音、口型、OTP 邮件和真实注册仍待检查。具体状态以 `CURRENT_STATUS.md` 为准。

## 2026-10-21 · 最终 UI 续验
本轮范围是报告可读来源标签、遗留状态说明和当前版本本地 smoke，不新增产品功能。R2 用任务名称替代内部 ID；隐私管理与维护页说明对齐现状；导出证据与 API 契约保持原样。验收为 lint、45 项测试、TypeScript、生产 build、密钥扫描、八路由和旧路由重定向 smoke，以及已有合成报告三尺寸读取。
