# LIMEN 临界

面向医学生的跨学科探索工具：从个人经历与职业兴趣出发，通过真实资料和模拟职业任务，形成可核对的下一步行动记录。支持继续医学，也支持探索 AI / 计算机、生物医学工程及医学信息学。

## 在线体验

- [正式网站](https://limen-azure.vercel.app)：当前公开生产版本。
- [新版功能测试站](https://limen-br99jfa0q-sakura-lzs-projects.vercel.app)：包含后续功能，需要 Vercel 项目访问权限。
- `public/previews/`：持续设计中的独立界面原型，与正式 Next.js 页面分开。原型存在不代表其中全部业务已完成真实接口验收。

仓库会继续更新；正式网址与工作区可能处于不同发布阶段。最新边界见 [当前状态](docs/CURRENT_STATUS.md)。

## 产品流程与能力

个人画像 → O*NET Mini-IP 30题 → 初步画像 R1 → 职业体验 → 目标与时间条件 → 行动规划 R2。

- 画像与报告：私有保存、恢复、证据引用、报告输入过期检查及成果导出。
- 方向知识库：九个跨学科方向及独立医学入口，支持官方资料、招聘、招生、行业和学习信息检索。
- 职业体验：10个方向、14个基础模板，项目/面试共28条路径；三阶段操作、反馈、复盘及成果导出。
- 数字人：按方向分配四组人物，用户主动连接，通过服务端代理管理会话。
- 社区：验证登录后匿名展示，支持发布、本人删除及举报。
- LIMEN-Match：确定性解释与缺失覆盖率的阶段实现；真实评分标准尚待审核。

知识库本阶段记录为38个官方来源、127条资料、270条事实实例，属于代表样本，并非全国完整职业或招生数据库。重复引用同一来源不算独立证据。

## 本地运行

需要 Node.js 22+、npm，以及自行配置的 Supabase 项目。仓库不包含真实密钥或个人数据库。

```bash
npm ci
```

将 `.env.example` 复制为 `.env.local`，在本机填写服务端配置。按 [数据库说明](docs/SUPABASE_SETUP.md) 设置匿名 Auth、迁移与 RLS；连接既有数据库时先核对迁移历史，不重复执行。

```bash
npm run dev
```

打开终端输出的本机网址。O*NET、报告 AI 和数字人需要各自有效配置；第三方服务失败会报告错误，不用假结果代替真实返回。现有公开部署所用知识库资料不随 Git 克隆自动写入新数据库；知识库结构与采集/导入说明见 [知识库说明](docs/KNOWLEDGE_BASE.md)。

## 检查与部署

```bash
npm run lint
npm test
npm run build
npm run check:client-secrets
```

生产启动后，可用 `LIMEN_TEST_ORIGIN` 指向本机服务执行 `npm run test:smoke`。配置方式按操作系统设置环境变量。真实外部服务验收与 mock/simulation 单测分开记录。

Next.js 页面与API一起部署到 Vercel，数据存储在 Supabase。GitHub 仓库提供源码；GitHub Pages 不能运行本项目的服务端API、登录及报告生成功能。部署步骤见 [部署说明](docs/DEPLOYMENT.md)，新界面对接见 [接入约定](docs/BACKEND_PREVIEW_HANDOFF.md)。

## 当前验证范围与限制

本次功能发布前130项单测、lint、云端构建，以及30项线上接口检查通过，见 [发布验收](docs/testing/backend-preview.latest.md)。该记录不代表所有外部服务与所有页面均完成端到端验证。

数字人语音/ASR/口型、社区真实邮件、AI长期稳定性、中文题目人工校对及个人招生资格等仍有待验收或核实；详见当前状态。体验为标注 simulation 的教学场景，不提供临床诊疗建议，不把模拟成果解释为真实能力认证。

兴趣、能力迁移、知识缺口与报考条件分开展示；不推算录取概率。O*NET职业到中国方向的关联为 LIMEN 编辑性映射。原题关联、翻译说明与来源见 [O*NET与数据说明](docs/03_ONET_AND_DATA.md)。
