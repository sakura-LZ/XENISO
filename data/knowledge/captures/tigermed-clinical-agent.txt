前沿部署工程师-杭州
社会招聘
全职
浙江省·杭州市
2026-09-10 发布
工作职责
职位说明
本岗位是公司自研 AI Agent 平台在客户侧的技术代表，面向临床研究行业（CRO/药企）客户，负责将客户真实业务流程中的痛点转化为可运行的 AI Agent 应用，并完成从 POC 验证到私有化上线的端到端交付。该岗位区别于传统实施顾问与平台研发：核心产出是在客户环境中真正投入日常使用的 AI 应用。

工作职责
1. 深入客户现场调研业务流程（临床监查、医学写作、数据管理等场景），定义 AI 可解决的问题边界，产出解决方案设计；
2. 基于公司 Agent 平台快速构建 Agent 应用，包括 prompt/skill 编写、MCP 工具与数据处理管线开发、知识库搭建、多 Agent 协作拓扑设计；
3. 建立交付质量闭环：构建评测集、对齐客户验收标准、持续迭代直至达标；
4. 主导私有化部署与系统集成：在客户内网环境完成 K8s 部署、本地模型接入，以及与客户既有系统（EDC/CTMS/文档系统）的对接；
5. 支撑售前环节：技术演示、POC 快速验证、投标技术方案编写；
6. 将现场经验反哺产品：提炼客户共性需求，形成平台功能建议与可复用的行业资产（skill 库、场景模板）。
任职资格
任职要求
1. 3 年以上软件工程经验，Python 熟练，能独立完成数据处理、API 集成与工具开发；
2. 具备 LLM 应用的实际构建经验：完整参与过至少一个进入真实使用的 LLM 应用/Agent 项目（而非仅调用 API 或搭建 demo），理解 prompt 工程、工具调用、RAG、上下文管理的工程实践与常见失败模式；
3. 熟悉 Linux 与容器化部署，具备 K8s 基本操作能力，能在网络受限的客户内网环境独立排障；
4. 具备出色的沟通与需求抽象能力：能与非技术背景的业务人员（CRA、医学写作人员、项目经理）直接对话，将业务语言转化为技术方案，并具备需求边界管理能力；
5. 交付节奏感强，责任心强，习惯以周为单位交付可演示成果；接受出差/驻场。

补充项：
1. 具备 CRO/药企/医疗信息化行业背景：了解 GCP 与临床试验流程，或有 EDC/CTMS/eTMF 类系统实施经验；
2. 具备私有化交付经验：本地大模型部署（vLLM/SGLang 等）、离线环境交付、客户安全合规审查对接；
3. 具备售前技术支持经验：方案宣讲、投标、技术演示；
4. 具备文档智能相关经验：OCR、文档解析、结构化抽取与溯源。

岗位亮点
1. 参与行业前沿的 AI Agent 交付实践：自研 Agent 平台 + 私有算力集群 + 真实临床研究业务数据闭环；
2. 反馈回路短，现场判断可直接影响产品路线；
3. 与临床研究领域头部客户共建行业级 AI 应用。
